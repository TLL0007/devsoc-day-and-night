# devsoc-day-and-night
Minimal web application for DevSoc training program application.

## Overview
This project provides a simple productivity dashboard with features such as:
- Pomodoro study timer
- Todo list with persistent task tracking
- Panel for persistent quick notes
- Day/Night theme toggling
- Lofi audio player for night mode
- Easter eggs
